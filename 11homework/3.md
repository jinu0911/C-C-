**Q3. 위 2번 문제에서 `movePoint` 함수가 원본 구조체의 값을 성공적으로 변경하도록 코드를 수정하려고 합니다. (가)와 (나)에 들어갈 기호로 알맞게 짝지어진 것은?**

```c
// 함수 정의 수정
void movePoint(struct Point ( 가 ) p) {
    p ( 나 ) x += 10;
    p ( 나 ) y += 10;
}

// main 함수 호출부 수정
// movePoint(&p1); 
```

1. (가) `*` , (나) `.`
2. (가) `&` , (나) `->`
3. (가) `&` , (나) `.`
4. (가) `*` , (나) `->`

---

* **정답:** 4
* **해설:** 원본 데이터를 수정하려면 함수가 구조체의 **주소**를 받아야 하므로 매개변수는 포인터형인 `*`로 선언해야 합니다((가)). 매개변수 `p`가 구조체 포인터가 되었으므로, 내부 멤버에 접근할 때는 `->` 연산자를 사용해야 합니다((나)). 이 방식이 **'주소에 의한 호출(Call by Address/Reference)'**입니다.
