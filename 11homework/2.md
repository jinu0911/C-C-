**Q2. 다음 프로그램의 실행 결과로 알맞은 것은?**

```c
#include <stdio.h>

struct Point {
    int x;
    int y;
};

void movePoint(struct Point p) {
    p.x += 10;
    p.y += 10;
}

int main() {
    struct Point p1 = {5, 5};
    movePoint(p1);
    printf("x: %d, y: %d\n", p1.x, p1.y);
    return 0;
}
```

1. x: 15, y: 15
2. x: 5, y: 5
3. x: 10, y: 10
4. 컴파일 에러 발생

---

* **정답:** 2 x: 5, y: 5
* **해설:** 구조체를 함수의 인수로 전달할 때 포인터(주소)가 아닌 일반 구조체 변수로 전달하면 **'값에 의한 호출(Call by Value)'**이 발생합니다. 즉, `movePoint` 함수 안의 `p`는 `p1`의 복사본이므로, 함수 안에서 값을 변경해도 `main` 함수의 원본 `p1`에는 아무런 영향을 주지 않습니다.
