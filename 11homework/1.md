

**1번 문제 : 다음 중 구조체 포인터를 사용하여 구조체 멤버에 올바르게 접근한 것을 모두 고르시오.**

```c
struct Student {
    char name[20];
    int age;
};

int main() {
    struct Student s1 = {"홍길동", 20};
    struct Student *ptr = &s1;
    // ...
}
```

1. `ptr.age = 21;`
2. `*ptr.age = 21;`
3. `(*ptr).age = 21;`
4. `ptr->age = 21;`

---

* **정답:** 3, 4
* **해설:** 구조체 포인터에서 멤버에 접근할 때는 화살표 연산자(`->`)를 사용해야 합니다(4). 만약 마침표 연산자(`.`)를 사용하고 싶다면, 포인터가 가리키는 값 전체를 먼저 참조(`*ptr`)한 뒤에 접근해야 하므로 괄호로 묶어 `(*ptr).age` 형태로 써야 합니다(3). ②번은 연산자 우선순위 때문에 `*(ptr.age)`로 해석되어 컴파일 에러가 발생합니다.
