**Q5. 다음 프로그램의 실행 결과로 올바른 것은?**

```c
#include <stdio.h>

enum Color { 
    RED, 
    GREEN = 5, 
    BLUE, 
    YELLOW = 10, 
    BLACK 
};

int main() {
    printf("%d, %d, %d\n", RED, BLUE, BLACK);
    return 0;
}
```

1. 0, 6, 11
2. 1, 6, 11
3. 0, 2, 4
4. 1, 2, 4

---

* **정답:** 1. 0, 6, 11
* **해설:** 
* `RED`: 아무 값도 지정하지 않은 첫 번째 요소이므로 기본값 **0**입니다.
* `GREEN`: **5**로 지정되었습니다.
* `BLUE`: 이전 요소인 `GREEN(5)`에서 1 증가하므로 **6**입니다.
* `YELLOW`: **10**으로 지정되었습니다.
* `BLACK`: 이전 요소인 `YELLOW(10)`에서 1 증가하므로 **11**입니다.
